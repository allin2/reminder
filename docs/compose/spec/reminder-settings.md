# 闹钟持续时间与睡眠统一补发

2026-09-30 用户授权新增；通知形式已确认：每条事项各自通知，在同一时间补发。

- 「我的 → 闹钟持续时间」：1–30 分钟整数，默认沿用 Android 的 5 分钟。铃声和振动到时停止，不写 ACK 或完成；修改对未来响铃生效，不重置当前正在响铃的计时。原生重启恢复、Direct Boot 和快捷稍后都保留时长。
- 「我的 → 睡眠勿扰 → 统一补发时间」：当地 HH:MM，留空使用勿扰结束时间；不允许选择睡眠内的时间。补发时刻为本轮睡眠结束后的第一个指定时刻，白天睡眠结束后该时刻已过则使用次日。
- 沿用现有睡眠范围：普通事项延后；重要、关键和独立截止保护保留原规则。每条事项保留独立身份及操作入口，通知或闹钟载体遵循该事项既有选择。
- 原始 `triggerAt` / `localTrigger`、事项版本和轮次基准不因补发计算改变。前台推进、首页到期判定和原生预排共用 `lib/reminder.js` 的有效时刻；补发时间尚未到时打开应用不会提前提醒。
- 设置持久化成功后更新原生投影。保存失败留在表单、恢复旧内存设置并允许重试。新设置纳入备份恢复的白名单；旧数据缺字段使用默认值，旧备份不覆盖缺失字段。PWA 使用 v52 缓存。

验证入口：`npm test`、`python3 scripts/verification/browser-reminder-settings-check.py`、Android `:app:testDebugUnitTest`。开发机测试不能代替目标手机的实际声振时长与后台补发证据。
