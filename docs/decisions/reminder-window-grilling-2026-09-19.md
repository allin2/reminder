# Grilling 定案：整理硬窗口与实机边界

用户授权：“无需问我，按照 Grilling 推荐来决策”。取代 N4 待裁决，不扩大到 schema5/G01 或多闹钟队列。

1. 普通整理提醒采用 `[窗口起点, 窗口终点)`，60 分钟间隔、首次加最多两次补提醒。默认只排 21:30/22:30，不强求三次。
2. 勿扰顺延后仍须在窗口内，等于或越过终点均不排；整个窗口被勿扰覆盖则该窗口不投递。
3. 跨午夜属于前一晚同一窗口；起止相等视为空窗口；零点/零分钟是有效设置。
4. 主动“稍后”有独立一次额度，允许越窗但遵守勿扰；宽限期从顺延后的时刻起算。
5. 多闹钟保持单声源替换，记录 REPLACED，不新增队列、不声称逐个全屏展示；旧投递不能误停新投递，不写假 ACK。
6. 允许新包覆盖安装、隔离测试事项、后台/熄屏/冷进程测试；保留用户数据与旧包。不改系统时钟、时区或权限，不整机重启，不绕过设备安全确认。
7. 验收绑定当前 APK SHA，排程/收到/声振/窗口可见分别记录；安装未完成则新候选投递为 NOT_PERFORMED。

实现范围：native-reminders 的硬窗口、跨午夜剩余排程；app-core 的首发/补发预算、零点设置、勿扰与稍后；测试及相关文档。
