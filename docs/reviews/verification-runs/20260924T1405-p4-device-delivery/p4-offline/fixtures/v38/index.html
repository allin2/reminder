新手指南与核心概念

1. 「我知道了」≠「完成」

点击「我知道了」只代表你真正注意到了、停止这轮铃声催促。这件事仍未完成，会留在首页的「未完成」里，随时可查。

2. 「稍后提醒」重新安排

如果当下抽不出时间处理，点击「稍后提醒」可改到具体时间（或默认 2 小时后再次提醒）。

3. 「完成」结束并归档

事情真正做好后点击「完成」，事项将归档保存；周期事项会自动推进到下一期。

4. 「右上角 ×」只关本次响铃

响铃时点右上角 × 只停止当前铃声，不算「我知道了」，也不算完成。

5. 两种模式自由切换

熟悉这些规则后，可随时在「我的」切换为正常模式，消除按钮释义小字，界面更紧凑清爽。
