## 修复内容（`lib/app-backup.js`，唯一改动文件 + 测试 + SW 版本号）

### G02 · 持久化确认前提示导入成功（备份可靠性阻断项）

`importDataFile()` 现在 `await deps.save()` 之后才 `render()` 和报「导入成功」：

- 注入的 `save()` 返回权威提交 Promise（app-core `saveAsync` 的 `runCommit` 链）——
  成功提示的时间点 = 提交兑现的时间点；
- 提交拒绝 ⇒ 「导入失败 · 数据未能保存，请重新导入」，**不报成功、不误报
  「文件格式不正确」**（内层 try/catch 把提交失败与格式错误分开，文件的功劳不冤枉）；
- 提交失败时内存状态**保留**（与 app-core 保存失败路径同一语义，不清空）。

### G01 · FileReader 读取失败静默

补上 `reader.onerror` / `reader.onabort`：

- 读失败 ⇒ 「导入失败：文件读取失败，请重试」；
- 读中止 ⇒ 「导入失败 · 文件读取已取消」；
- 反馈止步在读取层：不触发确认框、不触发提交、不渲染。

### SW 缓存版本

`lib/app-backup.js` 内容变了 ⇒ 按本仓契约换缓存名 v12 → **v13**（脚本 URL 未变，
预缓存按 URL 存，不换名则已装用户永远吃旧内容）。
