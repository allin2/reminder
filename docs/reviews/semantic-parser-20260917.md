# 中文相对提醒解析修复（2026-09-17）

## 问题与修复

在当前 main（基准 HEAD acbe3c539c88f00d836d448dafc31addf1496c90，已有未提交修改）复现：
“三分钟以后提醒我”被“以后”的模糊规则接管，返回 low 和一周后；产品保存时转入兜底流程。

- `lib/parse-cn.js`：先独立提取完整时长，再应用日历或模糊规则。支持秒、分钟、小时、钟头、天、周、星期，以及中文数词、全角数字、小数、半单位、复合时长和“过……／……后／以后／之后”。
- 秒、分、小时按当前参考时刻增加时长，保留秒与毫秒；整数天、周先按本地日历递增，未附钟点时保留当前时刻（原“几天后”规则默认上午十点）。天数附明确钟点时使用该钟点。
- 非正时长、重复或倒序单位、多个冲突时间不标为精确识别，沿用应用的低置信度确认路径。并非完整中文语义模型；模糊时长和复杂多事件语句仍需确认。
- 保留事项标题、标签与原文；只有“提醒我”而没有事项内容时，以原句作为标题。
- `app-core.js`：明确相对时长使用现有 elapsed 调度机制，避免 wall-clock 的分钟表单值在原生对账时截断秒数。用户手选时间继续优先；编辑时传递调度类型。
